# M9.9 · Exercise: whiteboard practice

Har system ke liye 30 minute ka timer lagao aur `00_how_to_whiteboard.md` ke 7-step structure mein design karo
(requirements → baseline → architecture → bottlenecks → failure modes → scaling → trade-offs).
Kaghaz par ya Mermaid mein. Phir mujhe bhejo, main senior reviewer ki tarah feedback dunga.

1. **Meeting summarizer:** Zoom/Meet recordings → summary + action items → Slack. 5,000 meetings/day, 30–90 min each.
2. **Resume screener for a Lahore recruitment agency:** 2,000 CVs/day (PDF, kuch scanned), job description ke against ranking + reasons. Bias aur fairness ka khayal.
3. **Voice bot for a clinic:** phone par appointment booking, Urdu/Punjabi/English, < 1s response start.
4. **SQL analytics assistant:** "Pichle mahine Lahore mein sab se zyada kaun si watch biki?" → SQL → chart. Database mein 50 tables.
5. **Document Q&A for a law firm:** 200k PDFs, strict access control (har lawyer sirf apne cases), citations mandatory.

Bonus: teeno case studies ke "Interviewer probes" ke jawab **bol kar** record karo (2 minute per answer) aur suno.
